# CA Foundation Planner — Android Studio project

A starter Android app project built with Kotlin and Jetpack Compose.

## Features
- Daily schedule from 24 October to 8 December 2026
- Weekday target: 6 study hours; weekend target: 12 hours
- Chapter tracker for Accounting, Law, Economics, and Quantitative Aptitude
- Chapter 1 excluded from the active tracker
- Per-chapter lecture and 1-hour post-chapter practice/learning checkboxes
- Progress dashboard
- Sunday test tracker and December revision checklist
- Progress stored locally on the device using SharedPreferences

## Open and run
1. Extract this ZIP.
2. Open the `CAFoundationPlanner` folder in Android Studio.
3. Allow Gradle sync.
4. Run on an Android device or emulator (Android 8.0 / API 26 or newer).

## Notes
- This is a starter source project, not a signed APK.
- The daily schedule tab provides a repeatable two-subject plan and test days. The chapter tracker preserves the lecture durations supplied in the study plan.
- Android Studio may update Gradle/SDK components during first sync.
